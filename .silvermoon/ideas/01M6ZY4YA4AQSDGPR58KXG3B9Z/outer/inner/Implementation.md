# Implementation

## Steps

### I-S01: 分离本地只读历史查询

为 sessions/turns 的 list/get 和 events list 提供无服务只读入口，复用校验、分页和公开输出语义。不得创建数据库、迁移、恢复执行或申请写者所有权；缺失、损坏和版本不兼容必须显式报错。配置定位不得依赖 Agent 可启动或凭据可用。

### I-S02: 接入按需启动与复用

本地 sessions create、turns start 自动发现或启动同一数据目录的唯一服务；定义启动互斥、就绪确认、私有发现信息及启动错误传播。取消必须定位真实工作所有者，不因服务缺失启动替代进程并宣称成功。显式 URL 和 ACPLUS_URL 保留 HTTP 路径；同步更新 CLI/API 文档。

### I-S03: 实现空闲安全退出

仅自动启动服务启用空闲宽限期；创建后的连续命令可复用。执行、登录流程和其他在途操作不得被空闲退出打断；退出与新请求竞争需有明确处理。退出前提交数据、关闭 Agent、释放所有权；保留 unknown 的对账边界，重启仅使用已支持的 resume/load，不重放历史。

## Acceptance criteria

### I-AC01: 历史查询无副作用且兼容

测试无服务及服务正在写入时的查询，验证提交快照、分页、过滤和输出与 HTTP 历史接口一致，且无进程启动或数据库写入；覆盖缺失、损坏及不兼容数据库。

### I-AC02: 并发启动与模式隔离可靠

通过进程集成测试证明并发命令只产生一个写者，启动失败显式可见；显式 URL 不自动启动、本地取消不伪造成功，显式 serve 保持常驻。

### I-AC03: 空闲退出不丢失执行证据

用可控 Agent 验证长执行期间不退出、空闲达到约定阈值后退出、退出竞争及再次启动；终态和事件先持久化，异常结果不被重放。运行 pnpm check 验证完整包与现有行为。
