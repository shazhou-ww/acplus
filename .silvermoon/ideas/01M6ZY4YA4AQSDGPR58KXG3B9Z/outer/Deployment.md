# Deployment

## Steps

### D-S01: 验证独立安装的本地使用流程

使用明确构建的 tarball 在独立安装位置和私有测试数据目录验证无需手动 serve 的创建、执行、查询、空闲退出及再启动；记录平台与制品标识。

### D-S02: 验证兼容模式与恢复边界

在独立环境验证显式常驻服务、显式 URL 和 ACPLUS_URL，以及并发命令、取消和服务异常后的历史可读性。真实 Agent 验证仅在已有授权环境进行，明确平台和 resume/load 的支持边界。

## Acceptance criteria

### D-AC01: 安装后无需维护后台服务

独立安装的命令转录及进程观察证明无需手动 serve 完成执行，服务空闲退出后历史仍可读，后续执行可再次启动。证据放在本世界支持文件，不以源码测试代替安装验收。

### D-AC02: 原有服务模式与持久历史可用

安装验收转录证明显式服务不自动退出、指定 URL 不隐式起服务、并发只有一个写者，异常后不伪造完成或自动重放；文档给出已验证的平台和限制。此阶段不自动授权 npm 发布。
