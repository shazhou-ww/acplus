# Deployment

这是准备阶段的轻量现实验证初版；当前未实施、未部署，未授权 npm 发布。设计讨论位置见
[讨论进度](./inner/ideal/DISCUSSION.md)。

## Steps

### D-S01: 准备隔离安装验证

在明确的独立安装环境使用获批版本的本地产物，隔离配置、数据及 Agent 身份，不影响既有用户环境。

### D-S02: 验证真实使用闭环

使用真实支持的 Agent 验证显式服务启动、会话准备和配置发现、异步对话、历史查询及停止。

### D-S03: 记录外部结果与限制

记录实际产物、环境、结果与未覆盖能力；若后续需要发布，另行取得明确发布授权。

## Acceptance criteria

### D-AC01: 安装入口可用

通过隔离安装记录证明两个入口均可发现命令并返回获批的 JSON 契约，无依赖源码目录的假成功。

### D-AC02: 真实生命周期可复现

使用保留的调用与安全观察证明真实 ACP 会话、配置和执行闭环，以及终端退出不停止服务、显式停止的行为。

### D-AC03: 外部证据边界明确

验证记录可追溯到具体产物与环境，不泄露凭证；未验证的 Agent
/ 平台能力和不确定结果明确列出。
