# Implementation

这是准备阶段的轻量可调整初版，不代表已授权实施。当前设计讨论见
[讨论进度](./ideal/DISCUSSION.md)，最终实施范围以构想验收后的契约为准。

## Steps

### I-S01: 明确批准范围与兼容迁移

依据最终确认的 CLI
Spec 确定实施范围、接口迁移及受影响文档，不把候选示例当作已实现功能。

### I-S02: 实现共享语义与两个入口

在既有执行核心上实现获批的输入、资源和服务行为，保持身份隔离及未知结果不重放。

### I-S03: 验证契约与包形状

覆盖命令结果、错误和恢复路径，更新直接相关文档并运行既有检查；不在本阶段发布。

## Acceptance criteria

### I-AC01: 获批规格映射完整

通过命令清单与定向测试核对两个入口的语法、JSON 结果及迁移行为，无静默遗漏或未经批准的移除。

### I-AC02: 失败与安全边界可证明

通过故障及并发测试证明只读不启动、精确取消、真实配置确认、显式服务管理和不确定结果保留。

### I-AC03: 仓库验证通过

既有 `pnpm check` 通过，公共 exports / files
allowlist 保持预期；保存实际命令和结果作为证明。
