# Implementation

准备阶段轻量初版；实现阶段再细化文件和参数，交互依据见 [设计说明](./ideal/CLI-INTERFACES.md)。

## Steps

### I-S01: 提取共享执行能力

分离终端交互与业务编排，保持配置、传输、等待和服务所有权规则不变。

### I-S02: 接入双入口交互契约

新增 AI bin、平铺命令与非交互输出，整理 Human 分组帮助并保留兼容路径。

### I-S03: 完善测试和使用文档

更新两个入口的示例、包入口检查及交互契约测试，执行现有质量检查。

## Acceptance criteria

### I-AC01: 共享业务与兼容行为保持一致

通过本地、远程及双入口交替操作测试，证明业务结果一致，原有脚本兼容路径仍受保护。

### I-AC02: AI 契约可独立验证

通过 TTY 与非 TTY 测试证明无输入等待，并验证 JSON、退出码、恢复语义及完整帮助覆盖和体积。

### I-AC03: 双入口构建和质量检查通过

通过 `pnpm check` 和构建产物双 bin 检查证明两个入口可用；文档分别说明 Human 与 Agent 使用方式。
