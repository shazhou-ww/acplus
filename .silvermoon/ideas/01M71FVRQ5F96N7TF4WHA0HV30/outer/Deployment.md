# Deployment

准备阶段轻量初版；现实验收面向实际安装结果，不代表已授权发布。

## Steps

### D-S01: 验证实际安装入口

在隔离消费环境安装候选包，检查两条命令的版本、帮助和命令解析；registry 验证在 GitHub Actions 执行。

### D-S02: 验证双入口真实使用

使用隔离配置与测试 Agent，验证 Human 操作和 Agent 轮次调用共享同一会话及正确恢复行为。

### D-S03: 核对交付与迁移指引

核对实际消费包随附文档与兼容说明；如需发布，另获明确 tag 授权并遵循 Trusted Publishing。

## Acceptance criteria

### D-AC01: 消费环境可发现两个入口

实际安装证据证明 `acplus` 与 `acplus-ai` 均可执行，版本和帮助与候选包一致。

### D-AC02: 真实流程无交互误入或历史分裂

端到端记录证明 AI 无 stdin 等待，两个入口共用会话，并能区分提交、等待与最终执行状态。

### D-AC03: 交付结果可追溯

保留候选版本、安装来源与验证结果；若另行授权发布，记录 Actions 及实际 registry 安装证据，否则明确未发布。
