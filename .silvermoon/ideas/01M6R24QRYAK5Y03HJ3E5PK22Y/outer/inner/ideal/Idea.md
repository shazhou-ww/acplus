# 简化 AHPD 首次配置并交付 Canary

## 问题

AHPD 主后端已经通过真实验收，但首次使用仍需查阅仓库样例、手写多项路径；已安装的 npm 包不包含这些样例文档。

## 结果

用户通过显式输入生成可用的本地 AHPD 配置，按照标准说明准备外部运行时，并能安装经过验证的新 Canary。

## 边界

- 只生成配置，不自动下载运行时、启动服务、覆盖已有配置或发现和复制凭据。
- 延续 Linux 与 Copilot CLI 的已验收组合，不改变原有 HTTP、CLI、VS
  Code 能力或稳定版渠道。
- 配置中的运行时来源声明不是二进制完整性验证，工作区信任必须显式授权。

## 验收标准

- 已安装包可独立生成有效配置；帮助、错误提示、权限和拒绝覆盖行为有可复现证明。
- 标准安装说明与生成配置在真实 Ubuntu 上可用，不依赖仓库内未发布的样例文件。
- 指定 Canary 经 GitHub Actions OIDC 发布并通过实际安装与来源证明验证，`latest`
  仍为稳定版。
