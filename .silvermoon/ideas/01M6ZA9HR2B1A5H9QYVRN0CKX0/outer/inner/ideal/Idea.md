# 提供按需执行与离线历史查询的 ACP HTTP 服务

## 问题

当前 HTTP 服务绑定 AHP 宿主，历史查询依赖后端在线，无法独立保存和查询会话内容。

## 结果

提供直接控制 ACP
Agent 的标准 HTTP 接口：按执行请求启动 Agent，持久保存会话内容，后端停止后仍可只读查询。

## 边界

- 使用新 `/v2`，不兼容旧 AHP 接口，不隐式迁移历史或凭据。
- 创建 Session 只落库，首次执行才启动；记录消息、工具事件和状态，不保存认证信息。
- 不自动重放结果未知的执行，不把缓存历史当作后端上下文恢复。

## 验收标准

- 配置中的 ACP Agent 能通过 HTTP 完成真实执行。
- Agent 不运行或不可用时，仍可查询持久 Session、Turn 和事件，并按 Turn 过滤事件。
- 执行身份与记录覆盖情况明确；中断、取消、恢复失败不被伪装成成功。
