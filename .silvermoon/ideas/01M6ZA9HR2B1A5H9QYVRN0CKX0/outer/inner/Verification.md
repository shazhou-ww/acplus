## 已安装独立入口的真实结果

在授权的 Ubuntu 环境，使用 Node 24.22.2、Copilot CLI
1.0.107 和显式选定的已登录专用 profile：

- 冷启动 GET 与 Session 创建：所属服务的 Agent 子进程数始终为 0。
- 首次真实执行精确返回 `OK`，状态 `complete`，耗时 13,704
  ms，记录 9 个对应事件。
- 真实文件读取返回测试内容，记录 2 个工具事件；按 Turn 每页 1 条共读取 13 条，无重复或跨 Turn 混入。
- 真实取消确认 `state=cancelled`、`stopReason=cancelled`。
- 停止 Agent、重启 HTTP 并将可执行文件改为不存在的路径后，已完成文本与 13 条过滤事件仍可读取，Agent 子进程数为 0，认证观测为
  `stale`。
- 再次重启并继续原 Session，精确返回 `RESUME_OK`；12 条重放事件单独标为
  `replay`，当前 Turn 的 9 条事件不混入重放。
- 重复同一 Turn ID/原文返回已有 `complete`，不再次执行。

最终候选加入真实 profile 租约、派发回调和 SQLite schema
2 后，使用新的数据根目录再次验证：

- 精确返回 `FINAL_OK`，状态 `complete`，记录 7 条对应事件。
- 另一服务使用不同 dataDir、相同 profile 发起执行，得到
  `agent_profile_busy`，未派发模型请求。
- 重复同一 ID/原文仍返回已有完成状态。

旧的未发布开发数据库使用不同哈希编码，schema
1 被明确拒绝；最终候选使用全新 schema
2，不静默迁移或重新解释旧记录。全部 token、原始登录输出和完整 profile 内容均未进入证据。

## 已覆盖的故障与权限边界

- 持久准入、原文精确哈希、同 ID 冲突、跨 Session 外键与过滤。
- UTF-8 替换会混淆的不同孤立代理字符仍触发原文冲突。
- 未派发本地取消、实际派发回调前的取消、真实取消响应及未知结果。
- 已观察的后台歧义在派发前阻止复用；拒绝 Turn 不吸收派发前迟到内容。
- 初始化/进程/存储故障、关闭与重启、未知结果不自动重放。
- 认证方法区别、非敏感输入白名单、认证观测失效、不支持退出的明确错误。
- 非敏感环境字面量不被当作密钥；密钥脱敏不改变 UUID、序号和时间戳。
- 同服务规范化 profile 冲突及跨服务独占租约；租约只删除自身拥有的文件。

通用 ACP 不提供所有未披露后台工作的精确身份；实现不声称能够自动关联这种内容，也不以缓存重放构造原始后端上下文。目录/工具策略不是 OS 沙箱。
