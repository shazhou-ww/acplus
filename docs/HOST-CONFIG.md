# Legacy AHP host configuration

The current repository implementation uses direct ACP Agents and schema 2. Use
[AGENT-CONFIG.md](AGENT-CONFIG.md); there is no `hosts` registry, AHPD/VS Code
adapter, or automatic schema-1 migration in the new entry.

This path remains only as a navigation reference for historical AHP acceptance
records. The old configuration contract is available at its
[immutable source revision](https://github.com/shazhou-ww/ahplex/blob/3e771ebe92eb9eee3fa10caf029c2bdf44bac68a/docs/HOST-CONFIG.md).
Previously published packages are not changed by this repository cutover.
